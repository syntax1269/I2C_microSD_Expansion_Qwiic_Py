# Examples

| Example | Shows |
|---|---|
| `ex1_file_write_read.py` | Qwiic discovery, write, close, read back |
| `ex2_directory_and_card.py` | Directory listing, card info, version |
| `ex3_pins_and_neopixel.py` | Expansion pins, EEPROM save, NeoPixel frame |

Run any example with `python examples/<file>.py` from the repository root (or
from an environment where `qwiic_sd_expansion_py` and `sparkfun_qwiic_i2c` are
importable). Edit the address or bus driver near the top if your module was
re-addressed.
